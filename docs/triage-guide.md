# Triage Guide

Notes and investigation checklists for handling alerts generated by these rules.

## General Triage Principles
1. Check parent process lineage.
2. Verify user privileges and execution context.
3. Search for concurrent network telemetry.

### T1003.001 - LSASS Memory Access
- Verify granted access mask (`0x1010` / `0x1FFFFF`).
- Common benign sources: antivirus, VMware Tools, Process Explorer.

### T1053.005 - Scheduled Task
- Inspect task XML under `C:\Windows\System32\Tasks`.
- Review action binary path and arguments.

### T1021.006 - WMI Lateral Movement
- Look for `wmiprvse.exe` spawning shells or staging binaries.

## Splunk SPL Investigation Guidelines
- Correlate sourcetype `WinEventLog:Security` EventCode `4625` with source IP addresses.

### T1055.001 - Process Injection
- Identify SourceImage and TargetImage in Sysmon Event ID 8.
- Inspect memory protections with `windows.malfind` in Volatility 3.

### T1569.002 - Service Execution
- Inspect service binpath for unquoted paths or temporary staging directories.

### T1003.002 - Security Account Manager Dumping
- Immediate password reset required for local administrator accounts upon detection.
